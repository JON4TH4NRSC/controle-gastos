# Controle de Gastos Web

## Problema
Muitas pessoas não conseguem controlar seus gastos diários.

## Solução
Sistema web simples para gerenciar gastos.

## Como instalar
npm install

## Como rodar
npm start

## Como testar
npm test

## Tecnologias
Node.js, Express, Jest, ESLint
